The pause button nobody has to press.

A protocol publishes a red line in plain language and funds a bounty. Anyone who finds it being crossed says so, with evidence and a deposit. The validators read the evidence themselves, and if the line is being crossed the protocol stops in that same transaction.

A red line with no implementation

The obvious version of this project is a threshold, and a threshold belongs in Solidity. So the line below is the other kind. There is still a number in it. What no contract can work out is who the number applies to, because an actor is not a field in any ledger.

The red line it is being judged against

What a protocol has to add

Four lines. No inheritance, no proxy, no upgrade, and no key handed to anybody. The only thing given up is the right to keep paying out while a guard is up.

def _guard_is_up(self) -> bool:
    try:
        return bool(gl.get_contract_at(Address(self.guardian))
                    .view().halted(gl.message.contract_address.as_hex))
    except Exception:
        return False

It fails open on purpose. A guardian that cannot be reached does not stop you. Failing closed would make the guard the single point of failure for every protocol trusting it, so one bad deploy of ours would freeze all of them. A broken guard protects nothing, which is the world before you adopted it.

Anyone may raise it, one party may lower it. The owner can lower a guard only after a hold, because a guard that could be lifted as fast as it went up is a race between two transactions, and an attacker sends transactions faster than a person does.

What it will not do

It does not find exploits. Somebody has to see it and say so. What this removes is the wait between the seeing and the stopping, which is where the money usually goes.

It judges what is happening, never what might. A theoretical bug, a design somebody dislikes, a risk with no event behind it: all refused, and refused at the cost of the deposit. A pause button anyone can press with a paragraph is a denial of service with extra steps.
